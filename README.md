# Удам Бэхи Холбоо ТББ — Веб хуудас

«Удам Бэхи Холбоо» НҮТББ-ын албан ёсны landing page. Эмэгтэйчүүдийн нөхөн үржихүйн эрүүл мэнд, эндометриоз өвчний талаарх мэдлэг түгээх, байгууллагын 2025 оны үйл ажиллагааг танилцуулах зорилготой.

🔗 **Амьдрал дээрх хаяг:** `https://<таны-username>.github.io/<repo-нэр>/` *(доорх зааврыг дагаж идэвхжүүлнэ үү)*

## 🚀 GitHub Pages дээр үнэгүй байршуулах

### 1-р алхам — GitHub account
[github.com](https://github.com) дээр бүртгэл үүсгэ (имэйлээр, үнэгүй).

### 2-р алхам — Repository үүсгэх
1. Нэвтэрсний дараа баруун дээд буланд байгаа **+** → **New repository**
2. **Repository name:** жишээ нь `udam-bekhi-landing`
3. **Public** сонго (GitHub Pages public repo дээр үнэгүй ажиллана)
4. **Create repository** дар

### 3-р алхам — Файлууд оруулах
1. Шинээр үүссэн repo хуудсан дээр **Add file → Upload files** дар
2. Энэ багц доторх бүх файл, фолдерыг (`index.html`, `css/`, `js/`, `assets/`) чирж оруул
   - ⚠️ Фолдерын бүтцийг хадгал — `css/styles.css` гэдэг зам өөрчлөгдвөл зураг, загвар харагдахгүй болно
3. Доор нь **Commit changes** дар

### 4-р алхам — GitHub Pages идэвхжүүлэх
1. Repo дотор **Settings** таб руу орох
2. Зүүн талын цэснээс **Pages** сонго
3. **Build and deployment → Source:** `Deploy from a branch`
4. **Branch:** `main`, folder: `/ (root)` сонгоод **Save**
5. 1–2 минутын дараа дэлгэцэн дээр ногоон тэмдэгтэй линк гарч ирнэ:
   `https://<username>.github.io/udam-bekhi-landing/`

### 5-р алхам — Шинэчлэлт хийх
Дараа нь текст, зураг солих бол:
- Repo дотор тухайн файл дээр дарж **✏️ Edit** (харандаа icon) → өөрчлөлт хийгээд **Commit changes**
- GitHub Pages 1–2 минутын дотор автоматаар шинэчлэгдэнэ

## 🌐 Өөрийн домэйн холбох (сонголт, төлбөртэй)

`github.io` бус жишээ нь `udambekhitbb.mn` гэсэн өөрийн домэйнтой болохыг хүсвэл:

1. Монголын registrar-аас (жишээ нь datacom.mn) `.mn` домэйн худалдаж ав
2. Домэйн удирдлагадаа GitHub-ийн зааврын дагуу DNS `CNAME` бичлэг нэмнэ
3. Repo **Settings → Pages → Custom domain** талбарт домэйнээ бичиж хадгал

GitHub Pages өөрөө үргэлж үнэгүй хэвээр байна — зөвхөн домэйн худалдан авалт төлбөртэй.
